## 貢獻指南

感謝你對北科餐廳地圖的興趣！我們歡迎任何形式的貢獻，無論是報告錯誤、提出建議或直接參與開發。以下是一些貢獻的指引：

### 餐廳資料 (CSV)

若要編輯餐廳資料，請登入北科 Gmail 帳號後直接編輯[此 Google 試算表](https://docs.google.com/spreadsheets/d/1aTIJGztYUYxPRU1O_7dT8Iwbl05r_YGu224_NYiZWtg/edit?usp=sharing)。

### 前端開發 (Nuxt.js)

1. **Fork** 此專案。
2. **Clone** 你 fork 的專案。
3. 在專案資料夾中執行 `pnpm i` 以安裝依賴。
4. 執行 `pnpm run dev --host` 開啟網頁預覽。
5. 執行 `pnpm run build` 建置專案，確認建置無誤後再進行推送。
6. 將更改推送到你的 GitHub，並發送 PR 到原專案。
7. 等待審核。

### 聯絡與支援

如有任何問題，歡迎在 [Discord](https://to.ntut.club/discord) 或透過 Issues 提問。
